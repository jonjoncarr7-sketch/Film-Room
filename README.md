# Film Room

NFL research tool: player prop hit rates with matchup and coverage context, weekly game breakdowns, Best Spots, a bet slip calculator and a pick tracker.

- `index.html` is the whole site. It is rebuilt every Tuesday from the scripts in `kit/`.
- `live.json` holds live scores, injuries, weather and official stats. It is refreshed hourly on game days and a few times on Fridays and Saturdays. The page checks it every minute.
- Data: nflverse (https://github.com/nflverse/nflverse-data).

Research tool only. 21+. If betting stops being fun, call 1-800-GAMBLER.
